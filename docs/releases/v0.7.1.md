# InferDoctor v0.7.1

v0.7.1 is a documentation and package-metadata hotfix for the v0.7 release.

## Changes

- Makes OrcaRouter visible in the PyPI package summary and README first screen as InferDoctor's first built-in hosted-provider preset.
- Adds package keywords for OrcaRouter, RAG, agents, OpenInference, OpenTelemetry, and OpenAI-compatible providers.
- Clarifies that hosted-provider support remains provider-neutral and evidence-driven.

## Behavior

There are no diagnostic, provider-transport, security, API, or runtime behavior changes from v0.7.0.
